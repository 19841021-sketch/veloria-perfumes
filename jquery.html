LIBRERÍAS JAVASCRIPT

jQuery.

Una biblioteca de JavaScript creada para simplificar tareas frecuentes del desarrollo web.

¿Qué es jQuery?

jQuery es una biblioteca de JavaScript que facilita la manipulación del HTML, el manejo de eventos, las animaciones y otras tareas comunes.

La sintaxis $

El símbolo $ es una de las características más reconocibles de jQuery y permite seleccionar elementos y trabajar con ellos de manera sencilla. 

$("#titulo").text("VELORIA PERFUMES");

JavaScript moderno vs jQuery

Aspecto JavaScript moderno jQuery
Sintaxis Puede utilizar APIs nativas. Sintaxis simplificada.
Dependencia No necesita biblioteca. Necesita cargar jQuery.
Uso actual Muy extendido. Continúa presente en muchos proyectos.
Ventaja Funcionalidades modernas. Facilita tareas repetitivas.

EJEMPLO INTERACTIVO

Animaciones con jQuery.

Este contenido puede aparecer y desaparecer utilizando jQuery. 
$("#elemento").fadeIn();

fadeIn() muestra un elemento utilizando una transición de opacidad. 

$("#elemento").slideToggle();

slideToggle() muestra u oculta un elemento mediante un efecto deslizante.
