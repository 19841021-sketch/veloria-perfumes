PUBLICACIÓN WEB

Hosting, dominios y DNS.

Conceptos necesarios para publicar un sitio web en Internet.

¿Qué es el Web Hosting?

El hosting o alojamiento web es un servicio que proporciona espacio y recursos en un servidor para almacenar los archivos de un sitio web y permitir que puedan ser consultados mediante Internet.

Hosting compartido

Varios sitios utilizan recursos de un mismo servidor. Es una opción sencilla para proyectos pequeños.

VPS

Un servidor virtual con recursos más independientes y mayor control.

Cloud

Utiliza infraestructura distribuida para proporcionar escalabilidad y disponibilidad.

¿Qué es un dominio?

Un dominio es la dirección que las personas utilizan para acceder a un sitio web.

www veloria .com

.com

Dominio de nivel superior muy utilizado para sitios comerciales.

.org

Frecuentemente relacionado con organizaciones.

Subdominio

Una sección independiente dentro de un dominio.

¿Cómo funciona el DNS?

El DNS permite relacionar un nombre de dominio con la dirección donde se encuentra un sitio o servicio.
