DATOS Y COMUNICACIÓN

JSON.

Un formato ligero utilizado para almacenar e intercambiar datos.

¿Qué es JSON?

JSON significa JavaScript Object Notation. Es un formato de texto utilizado para representar información de una manera estructurada y fácil de intercambiar.

¿Por qué es importante?

JSON es utilizado frecuentemente para enviar información entre aplicaciones, servidores y APIs.

Clave - valor

{
  "nombre": "VELORIA"
}

Arreglo

{
  "aromas": [
    "Floral",
    "Amaderado"
  ]
}

Objeto

{
  "perfume": {
    "nombre": "Nº01",
    "precio": 45
  }
}

Objeto de JavaScript 

const perfume = {
    nombre: "VELORIA Nº01",
    precio: 45,
    categoria: "Dama"
};

Cadena JSON 

{
    "nombre": "VELORIA Nº01",
    "precio": 45,
    "categoria": "Dama"
}

JSON y comunicación con APIs.

Una aplicación puede solicitar información a un servidor mediante una API. El servidor puede responder con datos organizados en formato JSON.
