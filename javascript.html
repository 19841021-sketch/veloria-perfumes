DESARROLLO WEB

JavaScript Vanilla.

El lenguaje que permite agregar comportamiento e interactividad a las páginas web.

¿Qué es JavaScript?

JavaScript es un lenguaje de programación utilizado principalmente para crear páginas web interactivas. Permite modificar contenido, responder a acciones del usuario y controlar diferentes comportamientos de una página.

¿Para qué se utiliza?

Se utiliza para crear botones interactivos, formularios, animaciones, menús, validaciones, galerías, calculadoras y muchas otras funciones.

Tecnología Función principal
HTML Define la estructura y contenido.
CSS Define diseño, colores y apariencia.
JavaScript Añade comportamiento e interactividad.

Variables

Permiten almacenar datos que pueden utilizarse durante la ejecución de un programa. 

let perfume = "VELORIA";

Funciones

Son bloques de código que realizan una tarea específica. 

function saludar() {
    alert("Bienvenido");
}

Eventos

Permiten ejecutar acciones cuando el usuario interactúa con la página. 

button.addEventListener(
"click", funcion
);
